# SpringBoot Student Registration System

A simple and efficient **student registration system** built using **Spring Boot**. This application allows managing student records, including registration, updates, and viewing details in a user-friendly way.

## Features

- Add new students
- View student details
- Update student information
- Delete student records
- Built with Spring Boot for easy scalability and maintenance

## Technologies Used

- Java 17
- Spring Boot
- Maven
- H2 Database (or MySQL, if configured)
- Thymeleaf (for front-end, if applicable)
